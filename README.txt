# نظام إدارة وثائق الهوية - تعليمات التشغيل

1. فك ضغط الملف المضغوط داخل مجلد جديد (مثلاً identity-vault-pro).
2. افتح موجه الأوامر / PowerShell داخل المجلد ونفّذ:
   npm install
   npm start
3. افتح المتصفح على:
   http://localhost:3000
   أو على الجوال عبر شبكة Wi-Fi المحلية باستخدام عنوان IP الخاص بالجهاز:
   http://YOUR_PC_IP:3000

بيانات الدخول الافتراضية للمدير:
- اسم المستخدم: admin
- كلمة المرور: admin123
